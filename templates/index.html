JURY EXPLANATION

How the System Works

01

Hashing

The Student ID is converted into a bucket index using a deterministic polynomial hash function.

02

Collision Handling

When two IDs map to the same bucket, records are connected as nodes in a linked list instead of overwriting each other.

03

Search

The system hashes the ID, jumps to one bucket and traverses only that bucket's chain.

04

Resizing

When the load factor exceeds 0.75, the table doubles in size and all records are rehashed.
